Tabla Interactiva

La siguiente tabla permite consultar los resultados de diferentes pruebas metabólicas utilizadas para la identificación de patógenos asociados a ETAs.

Para consultar información adicional sobre una prueba, coloque el cursor sobre el resultado.

Instrucciones: Coloque el cursor sobre una prueba para consultar diversas características.

  • Tipo de prueba
  • Especie
  • Resultado
  • Reactivo utilizado
  • Reacción/producto detectado
